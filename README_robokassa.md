# Настройка Robokassa

Для подключения оплаты через Robokassa в этом проекте понадобятся:

## 1. Данные магазина Robokassa
- `MerchantLogin` — логин магазина.
- `Password #1` — пароль для формирования подписи при создании платежа.
- `Password #2` — пароль для проверки Result URL уведомлений.
- При необходимости: тестовый режим и отдельные тестовые пароли.

## 2. URL-адреса, которые нужно настроить в Robokassa
- `Result URL` — серверный endpoint, куда Robokassa будет отправлять уведомление об успешной оплате.
- `Success URL` — страница, куда пользователь попадёт после успешной оплаты.
- `Fail URL` — страница, куда пользователь попадёт при отмене или ошибке оплаты.

## 3. Что нужно реализовать в проекте
- Серверный endpoint для создания ссылки/инициализации платежа.
- Серверный endpoint для приёма `Result URL` уведомлений от Robokassa.
- Проверку подписи Robokassa на сервере.
- Обновление статуса оплаты пользователя в базе (`profiles_les` или отдельной таблице платежей).
- Логику выдачи доступа после подтверждённой оплаты.

## 4. Переменные окружения
Рекомендуется подготовить такие переменные окружения:

```env
ROBOKASSA_MERCHANT_LOGIN=
ROBOKASSA_PASSWORD1=
ROBOKASSA_PASSWORD2=
ROBOKASSA_RESULT_URL=
ROBOKASSA_SUCCESS_URL=
ROBOKASSA_FAIL_URL=
ROBOKASSA_IS_TEST=1
```

## 5. Данные по платежу
Для каждого платежа в приложении обычно нужны:
- внутренний `invoice_id` / номер заказа;
- сумма;
- описание заказа;
- ID пользователя;
- тариф (например, `paid_1m` или `paid_3m`).

## 6. Что ещё важно
- Не хранить пароли Robokassa на клиенте.
- Подпись для оплаты и проверку callback делать только на сервере.
- Желательно хранить историю платежей в отдельной таблице.
- Перед боевым запуском проверить оплату в тестовом режиме Robokassa.

## 7. Минимум для старта
Минимально, чтобы запустить интеграцию, нужны:
1. Аккаунт и магазин в Robokassa.
2. `MerchantLogin`, `Password #1`, `Password #2`.
3. Серверные `Result / Success / Fail URL`.
4. Backend-обработчик создания оплаты и callback-уведомлений.
5. Логика активации подписки после успешной оплаты.
